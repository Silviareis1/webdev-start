# 🚀 WebDev Start

Landing page para inscrição em um **webinar gratuito de introdução ao Desenvolvimento Web**, desenvolvida como projeto de estudos durante a **Formação Desenvolvedor Full Stack Júnior 2026**.

O projeto tem como objetivo acompanhar, na prática, os conteúdos estudados em aula, começando pela estrutura HTML e pelo versionamento com Git e GitHub e evoluindo gradualmente para estilização, interatividade, consumo de API e responsividade.

---

## 📌 Sobre o projeto

O **WebDev Start** será uma landing page voltada para pessoas que estão começando na programação e desejam conhecer os primeiros conceitos de desenvolvimento web.

A página apresentará informações sobre um webinar introdutório e permitirá que o visitante realize sua inscrição por meio de um formulário.

### Slogan

> **Comece sua jornada no Desenvolvimento Web.**

---

## 🎯 Objetivo

Praticar os principais conceitos estudados durante a formação, utilizando tecnologias fundamentais do desenvolvimento Front-End.

O projeto será desenvolvido gradualmente, acompanhando a evolução das aulas.

---

## 🖥️ Estrutura planejada

A landing page deverá conter:

- Cabeçalho com o nome **WebDev Start**
- Menu de navegação
- Seção principal com apresentação do webinar
- Botão de chamada para ação
- Seção sobre o webinar
- Área com os conteúdos que serão abordados
- Informações sobre o evento
- Formulário de inscrição
- Integração com a API ViaCEP
- Rodapé

---

## 📚 Conteúdos do webinar

A página apresentará alguns dos principais conteúdos introdutórios do desenvolvimento web:

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

---

## 📝 Formulário de inscrição

O formulário será composto inicialmente pelos seguintes campos:

- Nome
- E-mail
- CEP
- Cidade
- Estado
- Mensagem

Posteriormente, o campo de **CEP** será integrado à API **ViaCEP**, permitindo preencher informações de endereço de forma automática.

## 🌿 Organização das branches

O projeto utilizará inicialmente duas branches principais:

```text
main
└── versão estável do projeto

develop
└── versão em desenvolvimento
```

O desenvolvimento será realizado principalmente na branch:

```text
develop
```

Após a conclusão e revisão das etapas, as alterações poderão ser integradas à:

```text

```

## 🎨 Design

O projeto terá uma identidade visual relacionada a tecnologia e desenvolvimento web.

A proposta inicial inclui:

- Azul como uma das cores principais
- Roxo/lilás como cor secundária
- Ciano para destaques
- Tipografia moderna e legível
- Layout simples e organizado
- Componentes fáceis de reproduzir utilizando HTML e CSS
- Boa legibilidade e contraste

O design será pensado para três tamanhos principais:

- Desktop — aproximadamente **1280px**
- Tablet — aproximadamente **768px**
- Mobile — aproximadamente **375px**

---

## 📱 Responsividade

A landing page será desenvolvida para funcionar adequadamente em diferentes tamanhos de tela.

A proposta é utilizar uma abordagem **mobile-first**, adaptando posteriormente o layout para tablets e desktops.
